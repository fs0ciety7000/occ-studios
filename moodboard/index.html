05 — Motion · ScrollTrigger

Le défilement raconte

Faites défiler : le manifeste s'embrase mot à mot et le tracé du dragon se dessine, tous deux pilotés par la position du scroll (scrub). C'est le type de mise en scène prévu pour la section Studio.

Nous croyons qu'un site se joue et qu'un jeu se visite. Entre le code et le récit, nous forgeons des mondes qui tiennent debout.

06 — Emblème

Quel blason pour le studio ?

Les trois logos fournis, posés sur le fond du site. Proposition : la tour enlacée comme emblème principal (hero, Open Graph), le dragon perché comme marque compacte (header, favicon).
